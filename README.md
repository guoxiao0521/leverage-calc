# 杠杆股计算器 (leverage-calc)

美股正股 ↔ 杠杆 ETP 的价位换算桌面工具。回答的是这一类问题：

> NBIS 跌到 208 的时候，NEBX 大概多少钱？我 24.5 的成本要回本，NBIS 得涨到哪？

![Tauri v2](https://img.shields.io/badge/Tauri-v2-24C8DB) ![Vue 3](https://img.shields.io/badge/Vue-3.5-42b883)

## 功能

- **价位对照表** —— 给定正股的一串价位，算出杠杆股的估算价、涨跌幅，可一键复制成 Markdown 表格
- **实时行情** —— 自动拉取正股和杠杆股的最新价（含盘前/盘后），也可以手动覆盖任一基准价做假设推演
- **多日衰减** —— 除了当日线性估算，还能按持有天数 + 日波动率 + 费率算出考虑每日重置损耗后的估值
- **反推** —— 输入杠杆股目标价，反算正股需要走到哪
- **持仓盈亏 / 回本价** —— 填成本和股数，表格多出盈亏两列，并把回本价那条线单独标出来
- **配对管理** —— 内置一批常见杠杆 ETP 配对，可增删改；「验证」会拉真实名称和近 60 日实测倍数来核对配置

## 计算口径

设正股基准价 `P0`、杠杆股基准价 `L0`、目标倍数 `k`（反向产品为负）。

**当日线性**（同一交易日内）：

```
L = L0 × (1 + k × (P/P0 − 1))
```

**多日持有**（每日重置 + 波动损耗 + 费率），`σ` 为日波动率、`T` 为交易日数、`f` 为年费率：

```
D(k) = exp( −(k²−k)/2 × σ² × T  −  f × T/252 )
L    = L0 × (P/P0)^k × D(k)
```

`(k²−k)/2` 这一项对 `k=1` 为 0（无杠杆无损耗）、对 `k=2` 为 1、对 `k=−2` 为 3 —— 反向产品衰减更快就是这么来的。

两式的反函数用于「反推」和「回本价」。

### 关于「多日一定比线性低」

这个流传很广的说法**只在震荡行情下成立**。真实关系分两种情形：

- 净变动小（震荡）→ 波动损耗占主导，多日估值 **低于** 当日线性，这才是通常说的 decay
- 净变动大（单边）→ 复利凸性占主导，多日估值 **高于** 当日线性

举例：`P0=229.38 / L0=27.479 / k=2`，正股跌到 190（−17.2%）。当日线性给 18.04；按 σ=5%、10 个交易日算，多日口径给 18.38 —— 反而更高，因为 2x 在线性口径下跌 50% 就归零了，而复利口径永远打不到 0。分界点满足 `(1+r)^k · D(k) = 1 + k·r`。

应用里把两列并排显示，就是为了让这个差别直接看得见。

## 数据来源

Yahoo Finance 的 `v8/finance/chart` 公开接口，无需 API key。请求全部在 **Rust 侧**完成 —— WebView 里直接 fetch Yahoo 会被 CORS 拦掉。

- 最新价：`interval=1m&range=1d&includePrePost=true`，取分钟序列里最后一个非空收盘价，因此盘前盘后也能拿到
- 日线：`interval=1d&range=6mo`，优先用复权价
- 交易时段由该报价的时间戳落在 `currentTradingPeriod` 的哪一段来判定

前端有 60 秒内存缓存，点「刷新」会绕过。

## 免责

内置配对表是起点不是权威 —— 单股杠杆 ETP 上新/清盘频繁，代码和倍数都可能变，用「验证」核对。

所有估算都是简化模型，忽略跟踪误差、折溢价、分红和融资成本。仅供参考，不构成投资建议。
